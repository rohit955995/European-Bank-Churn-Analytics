# 🏦 European Bank Customer Churn Analytics

## 📌 Project Overview

European Bank Customer Churn Analytics is a Machine Learning and
Data Analytics project designed to analyse customer behaviour and
predict whether a customer is likely to leave the bank.

The project combines data preprocessing, exploratory data analysis,
customer segmentation, interactive visualization and machine learning
based churn prediction.

---

## 🎯 Objectives

- Analyse customer churn patterns
- Identify high-risk customer segments
- Analyse churn by geography, age and gender
- Analyse financial behaviour such as balance and salary
- Study customer activity and product usage
- Build a machine learning model for churn prediction
- Provide business recommendations for customer retention
